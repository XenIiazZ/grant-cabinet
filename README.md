# Грантовый кабинет - FullStack проект с ИИ

## Описание

**Грантовый кабинет** - это полнофункциональное веб-приложение для подачи и управления заявками на гранты. Проект демонстрирует современный стек технологий в FullStack разработке с интеграцией искусственного интеллекта для автоматической оценки и анализа заявок.

**Основная цель:** Создание удобной платформы, где пользователи могут находить подходящие гранты, подавать заявки и получать автоматическую обратную связь через ИИ-модуль оценки.

## Ключевые особенности

### Для конечных пользователей:
-  **Умная подача заявок** - система помогает корректно заполнить все необходимые поля
-  **ИИ-ассистент** - мгновенная проверка заявки на соответствие критериям гранта
-  **Прозрачный статус** - отслеживание этапов рассмотрения заявки в реальном времени
-  **История заявок** - полный архив всех поданных заявок с фильтрацией по статусам

### Технические особенности:
-  **Интеграция ИИ** - машинное обучение для анализа текста и оценки качества заявок
-  **Полная безопасность** - JWT аутентификация, хэширование паролей, защита данных
-  **Адаптивный дизайн** - корректное отображение на любых устройствах
-  **Высокая производительность** - оптимизированные запросы, кэширование данных

## Технологический стек

### Бекенд (Backend)
- **Фреймворк:** FastAPI (Python 3.8+) - современный асинхронный фреймворк
- **База данных:** SQLite (разработка) / PostgreSQL (продакшн)
- **Аутентификация:** JWT (JSON Web Tokens) с Bearer токенами
- **Безопасность:** Bcrypt для хэширования паролей, CORS политики
- **ИИ-модуль:** Scikit-learn, NLTK для обработки естественного языка
- **Документация:** Автоматическая генерация через Swagger/OpenAPI
- **Валидация:** Pydantic для строгой типизации и валидации данных

### Фронтенд (Frontend)
- **Фреймворк:** React 18 с TypeScript для типобезопасности
- **Стилизация:** Tailwind CSS для быстрой и гибкой стилизации
- **UI компоненты:** shadcn/ui - доступные и стильные компоненты
- **Состояние:** React Hooks (useState, useEffect, useContext)
- **HTTP клиент:** Axios для работы с API
- **Маршрутизация:** React Router для навигации
- **Уведомления:** Sonner для toast-уведомлений
- **Иконки:** Lucide React для современных иконок


## Полное руководство по установке

### Предварительные требования
- **Python 3.8+** и **pip** для бекенда
- **Node.js 18+** и **npm/yarn** для фронтенда
- **Git** для управления версиями
- **SQLite3** (поставляется с Python) или **PostgreSQL** для продакшн

### Шаг 1: Клонирование репозитория
```bash
git clone <repository-url>
cd grant-cabinet

cd backend

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# На macOS/Linux:
source venv/bin/activate
# На Windows:
# venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env

python -c "from app.database.session import init_db; init_db()"

uvicorn app.main:app --reload --port 8000

# Установка зависимостей
npm install
